# BFS vs DFS — Water Jug Problem

Comparison of Breadth-First Search (BFS) and Depth-First Search (DFS) algorithms
using the classic Water Jug problem.

## Problem Definition

Two jugs with capacities of **5L** and **3L**. Starting from empty,
reach target volumes using fill, empty, and pour operations.

## Algorithms

- **BFS** — explores level by level, always finds the shortest path
- **DFS** — explores depth first, faster but may find longer paths

## Example Scenarios

| Goal (A, B) | BFS Steps | DFS Steps |
|---|---|---|
| (2L, 0L) | Shortest path | May vary |
| (4L, 3L) | Shortest path | May vary |
| (0L, 1L) | Shortest path | May vary |
